## 🛠️ Technical Process | Proceso Técnico

<details open>
<summary><b>🇺🇸 Technical Process</b></summary>

### 1. Data Cleaning & ETL
Performed data auditing in Excel using advanced functions and Power Query to handle nulls and normalize categories.

### 2. UI/UX Design
Designed a professional, "aesthetic" layout in PowerPoint to enhance readability and user engagement.

### 3. Data Modeling
Implemented a Star Schema and DAX formulas for accurate KPI tracking.
</details>

<details>
<summary><b>🇪🇸 Proceso Técnico</b></summary>

### 1. Limpieza de Datos y ETL
Auditoría de datos en Excel mediante funciones avanzadas y Power Query para manejar nulos y normalizar categorías.

### 2. Diseño de Interfaz (UI/UX)
Diseño de un layout profesional y estético en PowerPoint para mejorar la legibilidad y la experiencia del usuario.

### 3. Modelado de Datos
Implementación de un Esquema Estrella y fórmulas DAX para un seguimiento preciso de KPIs.
</details>
